# img/site/ — Owner-Only Site Assets

Personal images that belong to the site owner: profile photo, brand marks,
site favicons if they get promoted to files.

**Contributors:** please do not add, replace, or modify files in this
directory in a pull request. Anything visual you want to add for a blog
post goes in [`img/blog/`](../blog/) instead.

Current contents:
- `profile.jpg` — hero profile photo (referenced from `index.html`)
